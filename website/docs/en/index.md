# Hypothesis validator

You have a trading idea and you are not sure it works.  
This repo measures whether the sentence dies — on **trades on your machine** and **one locked ruler** — not web articles, not a story that changes with the model.

Same MA golden-cross sentence:

| | Web AI | Here |
|---|---|---|
| Gives you | “Classic trend; fake signals in ranges” | Bear / bull / recent tables of five KPIs |
| Recent-window CAGR (local) | — | **−3.1%** (source [README](https://github.com/TradeEdgeX/interpretable-ml-trading/blob/main/README.md)) |

You write the verdict. The AI must not use the web as evidence and must not declare for you.
