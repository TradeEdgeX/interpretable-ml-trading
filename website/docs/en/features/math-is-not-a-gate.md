# Math is not a gate

**One line:** Structure / volume / order flow can decide trade or no-trade; slow math only shrinks size and adds caution — it does not answer “is this a breakout?”.

## Wrong vs right

| Wrong | Right |
|---|---|
| Use Hurst / spectrum to filter out every historical false breakout, then report a pretty CAGR. | Price and structure write the contract geometry; math only penalizes noise and reduces exposure. |

Slow math as a hard gate is a hindsight filter that zeroes past failures — not edge.

## In this repo

The public MA-cross dummy mostly uses close tech. Order flow may gate (do / don’t). Hurst, WPT, Hilbert belong in execution caution, not as the master switch.
