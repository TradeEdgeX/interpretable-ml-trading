# Fill the template

**One line:** Write the phenomenon into falsifiable boxes before you touch the ruler. Empty slogans do not count.

## Boxes in plain words (MA-cross demo)

| Box | Plain | MA cross |
|---|---|---|
| **Sociology** | Who pays? What group behavior repeats? | Textbook 50/200 is a coordination ritual. Trend years: late chasers pay; range years: they pay each other’s fees. |
| **Math** | Which column? Which bar is knowable? (closed bar) | Closed-bar EMA50 / EMA200; event = sign change; void = close breaks EMA50. |
| **Statistics** | Which of the four classes? | **Beta / trend exposure** first — not pick alpha. |
| **Kill line** | Which window and KPI kills the sentence | Any window CAGR &lt; 0, or range drawdown worse than trend windows. |
| **Range** | Symbol / timeframe / which calendar | BTCUSDT · 2h · crypto three windows. |

Math → [What is a feature](../features/what-is-a-feature.md). Range → [How to choose](../framework/how-to-choose.md).

## Wrong vs right

| Wrong | Right |
|---|---|
| Only “buy the cross”, no payer and no kill line. | Anatomy (why a phenomenon) and five boxes (how to run / kill) both required. |
