# Talk to the AI

**One line:** You talk; the AI checks the template. Without “measure this”, no download and no backtest.

## What you can say

> Price above the 50-day, golden-cross the 200, exit if it breaks the 50. Trend years should pay; range years should not bleed. Write the template first.

> Has anyone measured a shallow −8% stop? Don’t backtest yet — only create the directory.

> This sentence fails. Record it.

## Must / must not

| Must | Must not |
|---|---|
| Fold into a template, fit the ruler, check lineage | Use web articles as evidence |
| Orchestrate download / features / backtest only after “measure” | Change your proposition |
| Retell local numbers with five KPIs | Write `verdict` for you |
