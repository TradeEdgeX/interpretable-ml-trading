# 流程

从一句想法到一张有五项数字的表，走五步：填模板 → 选哪一种回测 → 写成规则文件 → 跑回测 → 读表后写下结不成立。

## 五步

1. **填模板**：把想法写进 `docs/hypothesis_template.md` 的五格（怎么做、在什么市况里该赚钱、进出场规则、怎样算不成立、机器和人是不是同一句话）。
2. **选哪一种回测**：一个品种进出场，还是每天给全市场打分。
3. **写成规则文件**：把合同写成 `config/strategies/<archetype>/` 下面的文件。
4. **跑回测**：跑进出场脚本，或每天打分的脚本，印出三段、五项数字。
5. **读表后写下结不成立**：对照事先写好的标准，你自己写下「这句话成不成立」。

## 谁干什么

- **你**：填模板、读表、写下结论。
- **本仓库里的 AI**：帮你把模板翻译成规则文件、跑脚本、把表复述成文字。
- **程序**：算特征、撮合、印表。
