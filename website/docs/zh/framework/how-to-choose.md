# 怎么选

**一句话：** 数学点名什么，就下什么、用什么周期。不要为「显得科学」换一层无关数据。

## 问自己

1. 决策在哪根棒才知道？（闭棒）
2. 合同里的「一根」是多长？持有四天 ≠ 六根 2h。
3. 这个窗里品种上市了、有文件吗？没有 → 该段「无样本」，不能靠近窗单独过关。
4. 日历是不是**这个市场自己的**熊 / 牛 / 近窗？
5. 要用的列在不在特征库？缺了就登记 + 同层增量。

## 展厅对照（人话）

| 句子 | 粒度 | 日历 |
|---|---|---|
| 金叉 | 成交 → 2h | 币圈三段 |
| 资金费率 fade | 费率序列 | 币圈三段 |
| 周一反弹 | A 股日线 | A 股三段 |
| P99 追涨 | **tick** | 币圈三段 |
| 横截面打分 | 日频篮子 | A 股三段 · 另一台评测机 |

## 错 vs 对

| 错 | 对 |
|---|---|
| 用网页日线图解释 2h 数字；把币圈 2022 熊套到沪深 300。 | 模板里写死周期与日历文件；缺年写无样本。 |
