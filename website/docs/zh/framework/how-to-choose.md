# 怎么选

拿到一句话，先问自己三件事：量的是一个品种，还是一篮子？赚的是趋势、反转，还是日历？错了怎么走？答完这三问，你就知道用哪一种回测、配什么进出规则。

## 三个问题

1. **量的是一个品种，还是一篮子？**
   - 一个品种（一根棒上这一个名字）→ 按一根根进出场来量
   - 一篮子（每天给许多名字打分）→ 按每天买最热的一档来量

2. **赚的是趋势、反转，还是日历？**
   - 趋势（跟着均线、动量走）→ 先当成跟着市场走
   - 反转（跌多了买、涨多了卖）→ 先当成多出来的本事，或少数狠行情
   - 日历（周一、月末、特定日期）→ 先当成日历规律

3. **错了怎么走？**
   - 跌破某条线就走 → 趋势止损
   - 固定天数后走 → 时间到了就走
   - 反向信号出现就走 → 信号反了就走

## 一个例子

「比特币大涨时，AI 叙事山寨跟涨」：

1. 量的是一个品种领着另一个走 → 按山寨自己的棒进出场，但要用两个品种已经对齐好的数字。
2. 赚的是风险偏好跟着走 → 先当成跟着市场走。
3. 错了怎么走 → 事先写好：拿满几根就走，或跌破哪条线就走。
