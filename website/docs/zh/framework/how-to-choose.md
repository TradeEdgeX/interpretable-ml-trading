# 怎么选

**一句话：** 拿到一句话，先问三件事：量的是单品种还是一篮子？赚的是趋势、反转、还是日历？错了怎么走？答完就知道用哪台评测机、配什么合同。

## 三个问题

1. **量的是单品种还是一篮子？**
   - 单品种（一根棒上这一个币）→ 事件回测
   - 一篮子（每天对几十个币打分）→ 横截面回测

2. **赚的是趋势、反转、还是日历？**
   - 趋势（跟着均线、动量走）→ 先当 beta
   - 反转（跌多了买、涨多了卖）→ alpha 或肥尾
   - 日历（周一、月末、特定日期）→ alpha

3. **错了怎么走？**
   - 跌破某条线就走 → 趋势止损
   - 固定天数后走 → 时间止损
   - 反向信号出现就走 → 信号止损

## 一个例子

「BTC 领涨时，AI 山寨跟涨」：

1. 量的是跨品种传导（BTC → AI 山寨）→ 事件回测，但要两个品种的特征。
2. 赚的是趋势（领涨跟涨）→ 先当 beta。
3. 错了怎么走 → BTC 跌破某条线，或 AI 山寨跌破自己的线，就走。
