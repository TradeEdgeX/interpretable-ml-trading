# 什么是特征

**一句话：** 特征是事先算好的测量，不是预测。它只负责回答「现在这根棒上，价格 / 波动 / 费率 / 订单流长什么样」。

## 错 vs 对

| 错 | 对 |
|---|---|
| 「这个指标能预测涨跌。」 | 「这个特征描述当前状态；能不能赚钱，要看它配什么合同、在哪段行情量。」 |

同一个 `ema_50_200_cross_side`（50 日线在 200 日线上方还是下方），配趋势合同是一种策略，配反转合同是另一种。特征本身不站队。

## 本仓库怎么用

特征以列的形式存在特征库里，按月 parquet 落盘。比如节点 `ema_50_200_cross_f` 产出列 `ema_50_200_cross_side`：50 日均线在 200 日线上方记 +1，下方记 −1。回测开盘时读**上一根**的这列值，决定允不允许做。

仓库自带一套基础因子库（均线、交叉、费率、订单流、横截面动量等）。欢迎你基于这些列提出更多可验证的想法，也可以按 [特征库优先](feature-store-first.md) 的流程往库里加新列。
