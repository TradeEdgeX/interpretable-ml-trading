# 什么是特征

特征是事先算好的测量，不是预测。它只负责回答：现在这根棒上，价格、波动、费率或订单流长什么样。

## 哪种说法才对

| 错 | 对 |
|---|---|
| 「这个指标能预测涨跌。」 | 「这个特征只描述当前状态。能不能赚钱，要看它配什么进出规则、在哪段行情里量。」 |

同一个「50 日均线在 200 日均线上方还是下方」，配上「顺着趋势做」是一种策略，配上「反着做」是另一种。特征本身不站队。

## 在这个仓库里怎么用

特征以列的形式放在特征库里，按月存成文件。比如一个节点会产出一列：50 日均线在 200 日均线上方记 +1，下方记 −1。回测在开盘做决定时，读**上一根已经收完**的这一列，决定允不允许做。

仓库自带一套基础测量（均线、交叉、费率、订单流、每天给全市场打分的动量等）。欢迎你基于这些列提出更多能验证对错的想法，也可以按 [特征库优先](feature-store-first.md) 的流程往库里加新列。
