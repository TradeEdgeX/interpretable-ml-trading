# 什么是特征

**一句话：** 特征是事先算好、按月落盘的测量，不是回测里现场编的均线。

## 错 vs 对

| 错 | 对 |
|---|---|
| 回测循环里随手 `compute_ema()`，缺什么算什么。 | 合同用到的列先登记、建进特征库；缺列就补同一层，再跑尺子。 |

对话里随手算的一根均线，和特征库里按月算好的列，对不齐时钟，也复查不了。

## 本仓库怎么用

金叉读的是特征库里已经落盘的交叉列（例如 `ema_50_200_cross_side`），不是网页截图上的「日线金叉」。回测开着严格读库：列不在盘上就停，不许在热路径补算。
