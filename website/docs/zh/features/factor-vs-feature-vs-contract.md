# 因子 · 特征 · 合同

**一句话：** 三件不要混——因子/市况是你站在哪一侧；特征是测量；合同才写进/出。

## 错 vs 对

| | 是什么 | 例子 |
|---|---|---|
| **因子 / 市况** | 你站在哪一侧暴露上（常常只作许可） | 价在慢均线上方 → 许做多侧 |
| **特征** | 对几何或量能的测量 | 交叉变号、费率 z、根内 P99 |
| **合同** | 进 / 止 / 出写死的规则 | 金叉开多，跌破 EMA50 走 |

| 错 | 对 |
|---|---|
| 把十几个特征叠成一个分数，当成更强 alpha。 | 特征库只提供测量；Archetype YAML 才签合同。叠分数不会 magically 变成选点 alpha。 |

## 本仓库怎么用

金叉：慢均线位置可以当许可；交叉列是特征；跌破 50 是合同出场。特征库不替你决定仓位和止损。
