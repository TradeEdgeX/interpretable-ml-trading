# 特征五族

**一句话：** 先认族（这一族回答什么、不回答什么），再点名具体列。不要背 100+ 列名。

## 五族

| 族 | 回答什么 | 不回答 | 已量例子 |
|---|---|---|---|
| **收盘技术量**（EMA / ATR / 布林 / 星期） | 收盘可知的位置、交叉、日历 | 根内谁在推 | 金叉、周一反弹 |
| **订单流**（VPIN / CVD / 足迹 / P99） | 谁在推、根内极端成交 | 收盘价凑的假 delta | P99 + 布林追涨 |
| **拥挤与持仓**（资金费率、OI） | 杠杆拥挤是否极端 | 不是订单流 tick | 资金费率 fade |
| **慢数学**（Hurst / 频谱 / Hilbert） | 现在该有多小心 | 是不是突破 | （公开例子少用；见下页） |
| **横截面列**（动量、成交额 z、板块） | 今天相对一篮子谁更热 | 单品种事件时钟 | 动量+成交额（已 reject） |

收盘技术量只要 OHLC，便宜。订单流要 tick。费率是另一路文件。横截面走另一台评测机。

## 错 vs 对

| 错 | 对 |
|---|---|
| 为「显得科学」给日线日历句加 VPIN。 | 数学点名什么粒度，就下什么数据。 |
