# 特征五族

仓库里的特征按「量在谁身上」分成五族。你知道一句话属于哪一族，就知道去哪张配方表找列、用哪一种回测。

## 五族分别量什么

| 族 | 量在谁身上 | 常见例子 | 用哪种回测 |
|---|---|---|---|
| 单品种事件 | 一根棒上这一个品种 | 均线、交叉、波动、超卖 | 一根品种进出场 |
| 每天给全市场打分 | 每天一篮子股票互相比较 | 动量排名、成交额热度 | 每天买最热的一档 |
| 费率 / 订单流 | 永续合约的资金费率、特别大的单 | 费率拥挤、根内最大一笔 | 一根品种进出场 |
| 日历 / 星期 | 今天是周几、几号 | 周一下跌、月末 | 一根品种进出场 |
| 跨品种传导 | 一个品种领着另一个走 | 比特币大涨后山寨跟涨 | 一根品种进出场 |

## 怎么选

写假设时先问自己：我这句话量的是「一根棒上的一个品种」，还是「每天一篮子互相比较」？前者按一根根进出场来量，后者按每天排名来量。轴选错了，回测脚本就不对。
