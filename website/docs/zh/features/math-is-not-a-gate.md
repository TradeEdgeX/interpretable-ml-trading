# 数学不作门槛

你不需要先懂随机过程或偏微分，才能用这个仓库。你需要的是：会读一张有五项数字的表，并且会把想法写清楚——什么时候做、做错了怎么办。

## 哪种说法才对

| 错 | 对 |
|---|---|
| 「我数学不好，做不了量化。」 | 「我看得懂折合成一年、回撤、胜率，就能判断这句话在最近这段是不是亏钱。」 |

仓库里的数学主要藏在两处：特征怎么算（`docs/math.md`），和回测怎么撮合（`docs/framework.md`）。你不需要推公式。你只需要知道「收盘才知道的数字、第二天才能用」「至少看三段日子」「表上只报五项数字」，就能读报告。

## 什么时候才需要更多数学

- 想自己设计新特征 → 看懂 `docs/math.md` 里相关几节就够。
- 想改撮合逻辑（手续费、滑点）→ 需要读 `src/` 里负责进出场的代码。
- 只是验证一句话 → 填模板，再读五项数字，就够了。
