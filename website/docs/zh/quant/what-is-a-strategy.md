# 策略要事先写清楚，不是凭感觉

很多人会说：「均线金叉就买，感觉趋势能赚钱。」这几个字还不能算一份策略。

一份策略至少要写清四件事：

1. 什么时候允许做
2. 做错了怎么办
3. 这一笔最多亏在哪
4. 什么时候算做完了

只有这些写清楚了，别人才能按同一套标准复查，也才能验证这句话对不对。

## 哪种说法算一份策略

| 还不算策略 | 这才算一份策略 |
|---|---|
| 「均线金叉就买，感觉趋势能赚钱。」 | 「收盘在 50 日线上方，并且刚上穿 200 日线，才允许买入；跌破 50 日线就走。任意一段日子里，折合成一年是亏的，或者震荡那段回撤深于趋势那段，这句话就不成立。」 |

「感觉能赚钱」没法复查，也没法验证对错。事先写清楚就不一样：什么时候做、什么时候不做、做错了怎么办，都写在纸上。回测才能告诉你，这句话在熊市、牛市、最近这段日子里分别是什么样。

## 在这个仓库里怎么用

我们用均线金叉当练习。纸上要写清：怎么做、在什么市况里该赚钱、进出场规则、怎样算不成立、机器和人是不是同一句话。

程序里的规则，和你手写的清单，必须是同一句话。回测没有过关时，你读完报告，仍然按原来那句话下结论，而不是当晚另做一版「这回不一样」。
