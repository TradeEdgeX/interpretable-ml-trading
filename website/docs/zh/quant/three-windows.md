# 三段日历

**一句话：** 不要用最近半年给整句话判刑。至少看一段跌、一段涨、一段近窗，分列报数。

## 错 vs 对

| 错 | 对 |
|---|---|
| 「近六个月年化为正，策略成立。」 | 熊段、牛段、近窗各报五项 KPI；任一段按证伪线坏了，整句作废。近窗单独漂亮不能结案。 |

把三年行情平均成一条年化，会把坏年洗掉。A 股不要套币圈 2022 熊市日期——每个市场用自己的政权日历。

## 本仓库怎么用

- 币圈默认：`bear_2022` / `bull_2023_2024` / `recent_range_to_bear`
- A 股：`bear_2021` / `bull_924` / `chop_recent`（另一份日历文件）

金叉近窗年化约 −3.1%，对照事先写的证伪线，请你阅读这张表和策略后，自己写下结论。
