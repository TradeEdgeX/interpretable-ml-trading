# 闭棒

**一句话：** 开盘做决定时，不能用这一根已经走完的收盘价和特征。

## 错 vs 对

把一根 K 线想成「两小时的考试」：

| 错 | 对 |
|---|---|
| 考试刚开始，就用整场考试的分数做决定。 | 考试刚开始，只能用**上一场**已经公布的分数。 |

本仓库里：特征库的行索引是这根棒的**开盘**时刻，但这一行的高、低、收和特征，要等这根棒**收盘**才可知。开盘决策若读同一行 = 偷看未来。

同一套脚本，用「同根」曾把年化印成 50–70%；改成闭棒后干净段大约 −35%～−43%。那些漂亮数字**作废**。

```text
错: 墙钟 = 本根开盘 → 读本根已完成特征
对: 墙钟 = 本根开盘 → 读上一根已收盘特征
```

## 本仓库怎么用

特征库按月算好；回测开盘只读上一根。金叉用的交叉列也是闭棒后才可知，不是网页日线图上随手标的点。标签（未来收益）可以看未来，但禁止当入场特征。
