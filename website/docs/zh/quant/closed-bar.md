# 闭棒

开盘那一刻做决定时，你不能用**这一根还没走完、却已经写好收盘价**的数字。那等于偷看未来。

一根 K 线可以想成一场限时考试。考试刚开始，你只能用**上一场已经公布**的分数，不能用这场考完才知道的总分。

## 哪种做法才对

| 错 | 对 |
|---|---|
| 考试刚开始，就用整场考试的分数做决定。 | 考试刚开始，只能用上一场已经公布的分数。 |

在这个仓库里：特征库每一行的时间戳，标的是这根棒的**开盘**时刻。可是这一行上的最高价、最低价、收盘价和算好的特征，要等这根棒**收盘**才知道。如果你在开盘做决定时读了同一行，就是在偷看未来。

同一套脚本，曾经用「当根已经走完的数字」把折合成一年的涨跌印成 +50% 到 +70%。改成只读上一根已经收完的数字之后，干净的那段大约是 −35% 到 −43%。那些漂亮数字不算数，不能当成绩。

```text
错：墙上的钟走到这根开盘 → 却去读这根已经算完的特征
对：墙上的钟走到这根开盘 → 只读上一根已经收完的特征
```

## 在这个仓库里怎么用

特征按月事先算好，放进特征库。回测在开盘做决定时，只读上一根。均线金叉用的「交叉」这一列，也是收盘之后才知道，不是网页日线图上随手标的点。

用来对照的「未来涨了多少」可以看未来。用来决定进场的数字不可以。
