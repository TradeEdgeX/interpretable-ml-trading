# 先分类

先说清楚钱是从哪里来的，再选用哪把尺子。不要只用胜率，或「去掉最大几笔就变亏」，单独否定趋势策略，或否定靠少数大行情赚钱的策略。

## 四种来钱的方式

| 类型 | 钱从哪里来 | 不要这样做 |
|---|---|---|
| **Alpha**（多出来的本事） | 普通日子里，条件也对你更有利 | 只用牛市大赚来证明你有选股本事 |
| **肥尾**（少数狠行情） | 少数极端路径才付钱 | 为了提高胜率，把大行情砍掉 |
| **Beta**（跟着市场走） | 你站在趋势或大盘这一侧 | 用短过滤器去「保护」本来就要拿得久的暴露 |
| **无用** | 下跌、上涨、最近这段都不赚钱 | 继续扫门槛，把曲线救好看 |

可以这样记：市场上有一股大家一起付的钱（因子）；你站在这一股的哪一侧，叫 beta；扣完这些还多出来的钱，才叫 alpha。看起来像 alpha 的，大半其实住在 beta 里。

## 哪种判断才对

| 错 | 对 |
|---|---|
| 金叉胜率只有 35%，去掉最大三笔就变亏，所以「没有优势」。 | 金叉先当成 **beta / 跟着趋势走**。去掉最大几笔变亏，常常只是算术长这样，不能单独拿来宣判。 |

## 在这个仓库里怎么用

- 均线金叉 → 先当成跟着趋势走
- 特别大的单加上轨追涨 → 先当成少数狠行情
- 周一跌了后四天涨 → 先当成日历规律（即使很弱，也要按跨段尺子看）
