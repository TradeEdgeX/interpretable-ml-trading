# 先分类

**一句话：** 先说钱从哪来，再选尺子。不要用胜率或「去掉最大几笔」单独杀死趋势或肥尾。

## 四类（人话）

| 类型 | 钱从哪来 | 不要 |
|---|---|---|
| **Alpha** | 普通日子条件期望也更好 | 只用牛市大赚证明 alpha |
| **肥尾收割** | 少数极端路径付钱 | 为提高胜率砍掉右尾 |
| **Beta** | 站在趋势 / 市场等已知暴露上 | 用短过滤器「保护」长 beta |
| **无用** | 跨段都不赚钱 | 继续扫阈值救曲线 |

口诀：因子 = 共同付费来源；beta = 你在上面的暴露；alpha = 扣完这些还多的钱。看起来像 alpha 的大半住在 beta 里。

## 错 vs 对

| 错 | 对 |
|---|---|
| 金叉胜率 35%，去掉最大三笔为负 → 「没 edge」。 | 金叉先当 **beta / 趋势暴露**。去 Top-3 为负常常是算术形状，不是判决。 |

## 本仓库怎么用

- 均线金叉 → 先当 beta
- P99 大单追涨 → 肥尾右尾
- 周一反弹 → 日历 alpha（很弱也要按 alpha 尺子看跨段）
