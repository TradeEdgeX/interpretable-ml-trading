# 已量展厅

**一句话：** 这里按现象列出已经量过的句子，包括被判 reject 的。每张卡片写清：这句话是什么、三段五项 KPI、结论。

## 趋势

### 均线金叉（BTC · 2h）

- **句子**：收盘在 50 日线上方且刚上穿 200 日线开多；跌破 50 日线走。
- **三段五项 KPI**：熊市 +3.7% / 牛市 +3.0% / 近窗 −3.1%。
- **结论**：近窗年化为负，对照证伪线，这句话在近窗不成立。

## 费率

### 费率反转（funding fade）

- **句子**：资金费率极端时反向做。
- **三段五项 KPI**：熊市 +2.7% / 牛市 +3.0% / 近窗 −3.4%。
- **结论**：近窗年化为负，这句话在近窗不成立。

## 日历

### 周一反弹

- **句子**：周一开盘后买入，周五收盘前卖出。
- **三段五项 KPI**：熊市 +0.61% / 牛市 +0.46% / 近窗 +0.06%。
- **结论**：三段年化都接近零，这句话不成立。

## Beta

### 美股 SPY / QQQ 买入持有

- **句子**：买 ETF 会错过美股牛市；要跟上得选股或等超跌。
- **本机五项 KPI**：SPY 年化 13.7% / MaxDD −34.1%；QQQ 年化 20.4% / MaxDD −35.6%。超跌择时年化低于同窗买入持有。
- **结论**：先当 beta。原句已被打中。已 `--declare reject`。
