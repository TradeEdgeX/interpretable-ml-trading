# 词汇表

跳读用。详细页见导航。

| 中文 | English | 一句话 |
|---|---|---|
| 闭棒 | Closed bar | 开盘决策只读上一根已收盘的特征 |
| 三段 / 三段日历 | Three windows | 熊 / 牛 / 近窗分列，近窗不能单独结案 |
| 五项 KPI | Five KPIs | 年化、Calmar、胜率、最大回撤、Sharpe |
| 证伪 | Falsification | 事先写好：哪段哪个 KPI 坏了，这句话就作废 |
| 熔断 | Kill switch | 比策略时关掉；另跑一次开着只看账户保护 |
| 特征 | Feature | 事先算好、落盘的测量列 |
| 因子 / 市况 | Factor / regime | 你站在哪一侧暴露上（许可，不是进场点） |
| 合同 | Contract | 进 / 向 / 出写死的规则 |
| 特征库 | Feature store | 按月 parquet；开盘只读上一根 |
| 评测机 | Court | 锁死的回测，只印五项 KPI 分窗 |
| 门控 | Gate | 做 / 不做的硬许可 |
| 横截面 | Cross-section | 每天对一篮子打分，不是单品种事件轴 |
| 假设验证器 | Hypothesis validator | 本仓库的角色（名字仍是 interpretable-ml-trading）：把想法写成合同，用本机尺子出表；提供基础因子库，结论由你读报告后写下 |
