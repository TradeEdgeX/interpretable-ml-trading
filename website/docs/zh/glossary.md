# 词汇表

跳读用。详细说明见导航里的各页。

| 中文 | 英文 | 意思 |
|---|---|---|
| 开盘只看已经收完的数字 | Closed bar | 开盘做决定时，只读上一根已经收完的数字，不能偷看这一根后来怎么走 |
| 三段日子 | Three windows | 下跌、上涨、最近这段日子分开报；最近这段不能单独下结论 |
| 五项数字 | Five KPIs | 折合成一年、Calmar、胜率、最大回撤、Sharpe |
| 怎样算不成立 | Falsification | 事先写好：哪段日子、哪一项数字坏了，这句话就不成立 |
| 账户保护 | Kill switch | 比策略好不好时关掉；另跑一次开着，只看别把账户做穿 |
| 特征 | Feature | 事先算好、存成文件的测量 |
| 跟着市场走 / 市况 | Factor / regime | 你站在市场上哪一侧（允不允许做，不是具体哪一秒进） |
| 进出场规则 | Contract | 什么时候做、做错了怎么办、什么时候算做完了 |
| 特征库 | Feature store | 按月存放的测量文件；开盘只读上一根已经收完的数字 |
| 回测 | Court | 事先定好的比法，只印出三段日子、五项数字 |
| 许不许可做 | Gate | 做或不做的硬许可 |
| 每天给全市场打分 | Cross-section | 每天给一篮子名字排名，不是一根品种进出场 |
| 给 AI 用的工具库 | Hypothesis validator | 你提出假设，它帮你验证成不成立、写出报告，并把探索过程和结论保管下来 |
| Q & A | Q & A | 同一套问题的人话版：规则会不会骗人、为什么要分三段、相关为什么不能当成绩单 |
