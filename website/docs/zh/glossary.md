# 词汇表

跳读用。详细说明见导航里的各页。

| 中文 | 英文 | 意思 |
|---|---|---|
| 闭棒 | Closed bar | 开盘做决定时，只读上一根已经收完的数字 |
| 三段日历 | Three windows | 下跌、上涨、最近这段日子分开报；最近这段不能单独结案 |
| 五项数字 | Five KPIs | 折合成一年、Calmar、胜率、最大回撤、Sharpe |
| 怎样算不成立 | Falsification | 事先写好：哪段日子、哪一项数字坏了，这句话就不成立 |
| 熔断 | Kill switch | 比策略好不好时关掉；另跑一次开着，只看账户保护 |
| 特征 | Feature | 事先算好、存成文件的测量列 |
| 因子 / 市况 | Factor / regime | 你站在市场上哪一侧（允不允许做，不是具体哪一秒进） |
| 合同 | Contract | 什么时候进、往哪边、什么时候出，事先写清楚的规则 |
| 特征库 | Feature store | 按月存放的测量文件；开盘只读上一根 |
| 回测脚本 | Court | 事先定好的回测，只印出三段、五项数字 |
| 门控 | Gate | 做或不做的硬许可 |
| 每天给全市场打分 | Cross-section | 每天给一篮子名字排名，不是一根品种进出场 |
| 假设验证器 | Hypothesis validator | 本仓库的角色：把想法写成合同，用你机器上的尺子算出表；结论由你读报告后写下 |
| Q & A | Q & A | 同一套问题的人话版：规则会不会骗人、为什么要分三段、相关为什么不能结案 |
