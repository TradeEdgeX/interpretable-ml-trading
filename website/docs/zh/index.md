# 假设验证器

你有一个交易 idea，拿不准有没有用。  
这个仓库用**你机器上的成交**和**一把锁死的尺子**量它死没死——不是网页文章，也不是换一个模型就变的故事。

同一句均线金叉：

| | 网页 AI | 这里 |
|---|---|---|
| 给你什么 | 「经典趋势，震荡假信号多」 | 熊 / 牛 / 近窗三张五项 KPI |
| 金叉近窗年化（本机） | — | **−3.1%**（数字来源 [README](https://github.com/TradeEdgeX/interpretable-ml-trading/blob/main/README_CN.md)） |

判决由你写。AI 不许用网页当证据，也不许代你宣判。
