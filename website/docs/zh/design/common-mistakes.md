# 常见错误

**一句话：** 这些错会让你读不懂例子，也会让数字假好看。

## 清单

| 错 | 为什么坏 | 去哪读对的 |
|---|---|---|
| 加过滤救曲线 | 事后拧旋钮，不是事先合同 | [填模板](write-the-sentence.md) |
| 用胜率或去 Top-3 杀趋势 / 肥尾 | 尺子用错类 | [先分类](../quant/classify.md) |
| 只看近窗 | 近窗不能单独结案 | [三段日历](../quant/three-windows.md) |
| 把横截面句丢进单品种回测 | 评测机形状不对 | [三种评测机](../framework/which-court.md) |
| 为「显得科学」换无关数据 | 粒度必须跟数学 | [怎么选](../framework/how-to-choose.md) |
| 回测里现场算特征 | 时钟对不齐、不可复查 | [特征库优先](../features/store-first.md) |
| 用慢数学当硬门 | hindsight 过滤 | [数学不作门](../features/math-is-not-a-gate.md) |
| 头条合计 R | 分母漂移，误判长持 | [五项 KPI](../quant/five-kpis.md) |
| 开盘读同根 | 未来函数 | [闭棒](../quant/closed-bar.md) |
