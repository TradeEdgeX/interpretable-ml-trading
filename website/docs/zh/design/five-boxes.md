# 五格

五格是假设模板的骨架：怎么做、在什么市况里该赚钱、进出场规则、怎样算不成立、机器和人是不是同一句话。五格填不满，这句话就还没准备好被量。

## 五格分别写什么

1. **机制**：这句话为什么能赚钱？是趋势继续走、走到头回头、日历规律，还是一个品种领着另一个走？
2. **预期市况**：哪段行情应该赚、哪段应该亏？趋势策略在震荡段亏是正常的，但你要在「怎样算不成立」那一格写清：震荡段的回撤不能深于趋势段。
3. **合同**：什么时候允许做、做错了怎么走、这一笔亏在哪，事先写清楚。
4. **怎样算不成立**：事先写好，哪段日子、哪一项数字坏了，这句话就不成立。比如「任意一段折合成一年是亏的」，或「最近这段 Sharpe 低于 0」。
5. **落地**：用哪一种回测、哪个特征库、哪些品种、多长一根棒。程序里的规则和你手写的清单必须是同一句话。
