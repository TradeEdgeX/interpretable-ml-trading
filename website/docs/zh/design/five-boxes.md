# 五格

**一句话：** 机制、预期市况、合同、证伪、落地——机器 YAML 和手做清单是同一句。

## 五格

| 格 | 问什么 |
|---|---|
| **机制** | 发生了什么才允许做 |
| **预期市况** | 哪类行情该成立、哪类该失效 |
| **合同** | 错了亏哪、能不能加、何时结束 |
| **证伪** | 与验证标准同一句：坏了就死 |
| **落地** | 机器人与人手同一句 |

回测否了的句子，晚上也不能手做「感觉这回不一样」。`promote` 只表示在约定尺子上还没被证伪——不是今晚满仓。
