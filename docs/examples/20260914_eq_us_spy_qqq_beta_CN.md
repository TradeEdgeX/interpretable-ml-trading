# 买 ETF 会错过美股牛市吗

实验：[config/experiments/20260914_eq_us_spy_qqq_beta/](../../config/experiments/20260914_eq_us_spy_qqq_beta/)  
分类先当 **beta**（美股大盘 / 纳指 100 的股权暴露），不是选股 alpha。  
评测机是 **eq_us_daily**，不是 2 小时 `event_backtest`。人已 `--declare reject`。

> 买 ETF（SPY / QQQ）会错过美股牛市；要跟上爆发，得选股，或者等指数超跌再买。

这句话量的是「坐等超跌 / 再选股」能不能跑赢**同窗**无杠杆买入持有。赢了原句还活着；输了原句死。买入持有本身不是要 promote 的 alpha。

## 这一句在本仓库里怎么走完

你对网上的 AI 说：「买 ETF 会错过美股牛市，要跟上得选股，或者等指数洗完再买。」

它通常会讲英伟达、讲 2020 年 3 月谁抄到了底、讲「长期持有指数太笨」。没有同一把尺子，也没有「错了算谁输」。换一个模型，故事会换主角。

你对本仓库说同一句，并补上「测一下」。AI 不能用记忆回答。本仓库是**假设验证器**：优化的不是利润最大值，而是尽快确认这句话行 / 不行 / 在什么条件下行。路径是锁死的——

| 步 | 谁做 | 做什么 | 不做什么 |
|---|---|---|---|
| 1 | 人出句，AI 帮你收进模板 | 谁付钱、量什么、哪段数据、哪项 KPI 判死 | 不许改题成「再加点 RSI」 |
| 2 | 程序 | `validate` 验模板齐不齐；`index` 查有没有已结案的同一句 | 不许下载、不许回测 |
| 3 | 人说「测一下」 | 才下 SPY / QQQ 日线，才跑 `eq_us_spy_qqq.py` | 不走 `mlbot research run`（那条路只派 2h 事件回测） |
| 4 | 程序出表 | 同窗买入持有 vs 四条超跌 / 均线时钟，只报五项 KPI | 不写 `verdict:` |
| 5 | 人读表 | 对照事先写好的证伪线 `--declare` | 回测否了也不许晚上改手做 |

哲学上先分类：宽基 ETF 买入持有是这段样本上的**股权 beta**，不是要上线的 alpha。原句要活，必须证明「等超跌」或「必须选股」的全期年化高于**同窗**买入持有，且回撤不更深。选股本机没有宇宙，半句量不到；能量的半句——四条时钟——年化全部更低。人已 `--declare reject`。机器不把超跌写进 YAML；人也不按「等 RSI 再买才能跟上」手做。

下面七段把这条路展开：设计、数据、特征、为什么没有 IC、验证表、结论、报告怎么读。金叉那篇故事在仓库根目录 [README_CN.md](../../README_CN.md)；循环写在 [hypothesis.md](../hypothesis.md)，分工写在 [rd_playbook.md](../agent/rd_playbook.md)。

## 实验怎么设计的

```text
人出句（ETF 太慢 / 必须选股或等超跌）
  → 模板：社会 / 数学 / 统计 / 尺子 / 美股四段 / 五格
  → validate + 谱系（公开库此前无已结案同一句）
  → 日线法院 eq_us_daily：买入持有 vs 四条指数时钟
  → 人 --declare
```

不走 `mlbot research run`（那条路只派 2h `event_backtest`）。没有 FeatureStore 层，也没有横截面宇宙。

| 格 | 这一句 |
|---|---|
| 机制 | 基准：每个已收盘日全仓 SPY 或 QQQ。对照：等 RSI / 首次 −20% / MA200 再进场。标普点时选股本抽取未重跑。 |
| 预期市况 | 长牛年买入持有该拿走大部分复利；急杀年超跌时钟看起来「有效」；慢熊年固定持有日会斩在半山腰。 |
| 合同 | 日线闭棒；不加仓；择时摩擦 0；买入持有 100% 在市。熔断关。 |
| 证伪 | 选股或超跌择时的**全期年化高于同窗买入持有，且回撤不更深**，原句才还活着。任一段（或全期）择时年化更低，或选股 MaxDD 深于同窗 SPY，原句被打中。近窗子窗不可独自 promote。 |
| 落地 | 机器：`scripts/research/eq_us_spy_qqq.py`。人手同一句。不把选股 / 超跌写进 YAML 当 alpha。 |

对照四条时钟（信号在收盘 t 可知，仓位从 **t+1** 起；现金日收益记 0）：

| 模式 | 进场 | 出场 |
|---|---|---|
| `rsi_hold_40` | Wilder RSI(14) ≤ 30 | 再持有 40 个交易日 |
| `rsi_to_252_high` | 同上 | 收到回进场时的 252 日滚动前高 |
| `dd20_hold_60` | 相对历史峰值**首次**收盘 ≤ −20% | 再持有 60 个交易日 |
| `ma200` | 收盘站上 200 日均线 | 收盘跌破则下一根空仓 |

只报五项 KPI：年化 / Calmar / 胜率 / MaxDD / Sharpe。不要合计 R。

## 特征

这条法院**不读 FeatureStore**。没有 `features.yaml`，也不要在回测热路径里另写一套 `compute_*` 去「补」列——列就是日线收盘价，时钟在 [`src/research/eq_us_spy_qqq.py`](../../src/research/eq_us_spy_qqq.py) 里从 `close` 算。

| 列 | 怎么来 | 闭棒用法 |
|---|---|---|
| `close` | Nasdaq 拆分红后收盘 | 收益用已实现日收益；仓位用**上一根**信号 |
| RSI(14) | Wilder（对涨跌幅做 α=1/14 的 ewm） | `rsi[t] ≤ 30` 最早下一根才持仓 |
| 252 日前高 | `rolling(252).max()` | 目标位在进场当根已知；未满窗（NaN）不进场 |
| 峰值回撤 | `close / cummax − 1` | 只认**第一次**跌破 −20%，不是每次新低都重置时钟 |
| MA200 | `rolling(200).mean()` | `(close > ma).shift(1)`：今天收盘站上，明天才持仓 |

缺预热窗（RSI / MA200 / 252 日前高）的日子，对应时钟就是空仓，不是用未来值填。

## IC

**这条没有 IC 表，也不该有。**

IC（按日 Spearman：分数 vs 未来收益）是给**横截面打分、买前 N 名**用的探照灯，见 [涨得多又热的票](20260911_ashare_cs_mom_amount_CN.md)。本句是单品种 0/1 时钟，没有宇宙、没有分数、没有「更超跌的日子该不该第二天涨」这道题。

探照灯不能改题、不能当判决。结案只看同窗五项 KPI：择时年化有没有高于买入持有、回撤有没有更深。

若有人把 RSI 当连续分数去挖 overnight IC，那是另一句，要另开目录。

## 结论

分类：**beta**。宽基 ETF 买入持有是这段样本上的股权暴露基准，不是要上线的 alpha。

- 超跌择时（RSI / −20% 时钟）年化全部低于同窗买入持有 → 「等洗盘再买才能跟上牛市」被数字打中。
- MA200 把 QQQ 回撤从 −35.6% 压到 −21.9%，年化从 20.4% 降到 16.0%：这是**交保费**，不是 alpha。
- 选股本机未重跑。没有宇宙就不能用「必须选股」给原句续命。
- 去 Top-3 单票（英伟达等）只作分类，不能单独用来否这条袖套。

已 `--declare reject`。机器不把超跌 / 选股写进 YAML 当 alpha；人也不按「等 RSI 再买才能跟上」手做。判决不要手写 `verdict:`。

## 报告解读

读 `result.json` / 上面的表时，按这几条，不要自己另立尺子。

1. **先对窗，再比年化。** 每一行择时只和**同一标的、同一 `window`、同一锁日**的 `buy_hold` 比。不要拿 QQQ 择时去打 SPY 买入持有，也不要拿近窗去打全期。
2. **标题是年化，不是 ΣR。** `pnl_r` / 合计 R 不是五项 KPI。Calmar = 年化 / |MaxDD|。Sharpe 用日收益年化。
3. **胜率是在市日的上涨日占比**，不是「一笔交易」胜率。RSI 袖套在市只有约 21%，胜率略高说明不了它跟上了牛市——它把大部分上涨日让给了现金。
4. **在市比例是机制，不是彩蛋。** 超跌时钟年化低，主要是因为牛市里大部分日子空仓。这正是原句付钱的方式：把正常上涨日让给别人。
5. **MaxDD 变浅 ≠ 原句活着。** 证伪线是「年化更高 **且** 回撤不更深」。MA200 回撤更浅但年化更低，是保险，过不了尺子。
6. **这不是基金宣传里的 SPY 总回报。** 带子是拆分红后收盘，不含分红再投。两边用同一条价，相对比较仍成立；不要把 13.7% / 20.4% 贴到含分红曲线上去对年。
7. **`us_covid_2020` 的 −99% 年化不要当故事。** n = 24。急杀窗只证明日历盖到了，不能结案。
8. **`pit_stock_picking: not_run_no_universe` 是缺口，不是及格。** 原句的「得选股」半句本机没有量。没量就不能声称选股赢了或输了；能结案的只有超跌择时半句。
9. **买入持有分窗是分类，不是第二套判决。** `us_bull_2023_2024` QQQ +39.3% 说明牛段复利在买入持有手里；`us_bear_2022` −42.5% 说明 beta 会回撤。两者都不能把超跌时钟翻成 alpha。
