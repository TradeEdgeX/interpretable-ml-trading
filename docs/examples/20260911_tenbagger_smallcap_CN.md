# 十倍股是不是都得小市值、拿三四年

实验：[config/experiments/20260911_tenbagger_smallcap/](../../config/experiments/20260911_tenbagger_smallcap/)  
分类先当 **肥尾 / 小市值 beta**，不是选点 alpha。去 Top-3（或去最大几个十倍）只作分类，不单独否。  
评测机是 **cohort_hold**，不是 2 小时 `event_backtest`。人已 `--declare reject`。

> A 股涨十倍的，一般要在 100 亿市值以下，拿三到四年。

这句话量的是一条**已经发生过的历史规则**：入场日流通市值小、死拿满 3 或 4 个交易年，十倍是不是比大票更密，相对年化是不是更好。它**不能**量「未来谁会十倍、叙事还没走完」——那种句子没有成交、没有闭棒列。

## 这一句在本仓库里怎么走完

你对网上的 AI 说：「十倍股是不是都得小市值、拿个三四年？帮我找下一只。」

它会开始列名字、讲叙事。还没发生的故事没有成交、没有闭棒列，**本仓库不能量**。那不是假设，是调研。网上数「后来涨了十倍的有多少是小盘」，用的是未来贴标签——池子大，个数当然多。

你对本仓库说的必须是一句**已经发生过的规则**：「入场日市值 ≤ 100 亿，死拿满 3 或 4 年，十倍是不是比当时的大票更密，相对年化是不是更好。」先分类：肥尾 / 小市值 beta，不是选点 alpha。评测机换了：`mlbot research run` 只派 2 小时事件回测，这句话走 `cohort_hold`。市值用入场日成交额 / 换手率，不是今天的市值往回填。924 牛还拿不满 3 年，写无样本，不能拿「最近小票涨得好」续命。

表印出来：3 年十倍率两边都是 0.11%（88 次 vs 33 次，密度一样）。股灾入场的队列，小票相对年化更差。人已 `--declare reject`。哲学上：还没上市的名字没有历史；事后数个数是幸存者；reject 对机器和人手效力相同——不许再当「小票能稳定十倍」来做。美股同一句数学，这次没量，不能把 A 股表贴到纳指上。

下面七段把「能量什么 / 不能能量什么」和分窗表展开。

## 实验怎么设计的

```text
人出句（十倍股都得小市值、拿三四年）
  → 模板先分清：能量历史规则，不能量「下一家是谁」
  → validate + 谱系
  → 人说「测一下」才下载在市 + 退市日线、季度时点市值
  → cohort_hold：入场日分桶，小票 vs 大票，固定持有 3 / 4 年
  → 人 --declare reject
```

不走 `mlbot research run`（那条路只派 2h `event_backtest`）。评测机是 `scripts/research/cohort_hold.py`：每个入场季、每只当时在宇宙里的名字，按**入场日已知**的市值分到小 / 大两组，拿满固定年数，看终端倍数。

| 人想做什么 | 本仓库 |
|---|---|
| 调研**未来**谁会十倍、叙事还没走完 | **没有用。** 没有成交、没有闭棒列，不能当假设。 |
| 量一句**历史规则**：「入场日市值小、死拿 3–4 年，十倍是不是比大票更密」 | **有用。** 肥尾 / 小市值 beta。 |

| 格 | 这一句 |
|---|---|
| 机制 | 入场日流通市值 ≤ 100 亿元人民币的股票进来；持有 3 或 4 个交易年（252×3 / 252×4 根日线）；不择时加仓。 |
| 预期市况 | 小票池子的右尾更厚；大票对照不该同样十倍密集。熊段多数路径该很难看。 |
| 合同 | 时间出场；不做「已经十倍了再回看谁小」。闭棒市值。退市用最后收盘作终端。 |
| 证伪 | 任一段：小市值组相对大市值组的年化 ≤ 0，或十倍命中率不高于对照且回撤更深。近窗不能单独 promote。 |
| 落地 | 机器：`scripts/research/cohort_hold.py`。人手：只买当时已知小票、日记入场日、拿满年数。 |

| 模板格 | 这一句怎么写 |
|---|---|
| 社会学 | 十倍是少数路径上的彩票。付费方是追逐十倍故事的人。还没上市、还没涨的名字，没有历史可以量。 |
| 数学 | 入场日已知的流通市值；固定持有年数；禁止事后贴「十倍股」标签。 |
| 统计学 | 肥尾 + 小市值 beta。去最大几个十倍只分类。按入场日所在政权窗分列，不合成一条「十倍概率」。 |
| 验证标准 | 任一段相对对照年化 ≤ 0，或十倍率无差异且回撤更深。 |
| 数据范围 | A 股日线 + 时点市值 + `market_segment_ashare.yaml`。美股未量。 |

只报五项 KPI：年化 / Calmar / 胜率（倍数>1） / MaxDD / Sharpe。另外报十倍率作分类，不当单独判决。

## 特征

这条法院**不读**金叉那种 `features.yaml` 层。列是日线收盘、成交额、换手率，市值在 `cohort_hold` 里按入场日算。不要用「后来成为十倍股」回看当时市值——那是用未来贴标签。

| 列 | 怎么来 | 闭棒用法 |
|---|---|---|
| 前复权收盘 | 日线 qfq | 持有期收益用已实现路径；退市用最后收盘 |
| 成交额 / 换手率 | 当日行情 | 市值 = 当日成交额 / (换手率/100)，只用入场日 |
| 小 / 大 | 入场日市值 ≤ 100 亿 vs > 100 亿 | 分组在入场日已知；持有期内市值变大不改组 |
| 十倍 | 终端价 / 入场价 ≥ 10 | 标签可以看未来；**分组不可以** |

缺入场日市值的名字丢掉，不进分母。不要用今天的总市值往回填。

## IC

**这条没有 IC 表，也不该有。**

IC 是「今天的分数对未来收益」的 Spearman。本句没有每天打分、没有买前 20%。它问的是队列密度：入场日已经小的名字，拿满年数之后，十倍是不是更密、相对年化是不是更好。

把「入场日市值」当连续分数去挖「越小越容易十倍」的 IC，是另一句。探照灯不能改题。结案只看分窗相对年化和十倍率。

## 结论

分类：**肥尾极薄，主形态是小市值 beta。**

- 网上「十倍股都是小盘」是事后数个数：后来涨了十倍的名字里，小票个数多，因为池子大。入场日**密度**两边一样（3 年都是 0.11%）。
- 股灾入场的队列，小票相对大票年化更差；2018 年的 3 年窗也是。证伪线打中。
- `bear_2021` 小票年化明显好于大票，那是小市值 beta，不是十倍更密（十倍率 0.09% vs 0.12%）。
- 去 Top-3 几乎不动：不是靠三只传奇名字撑起来的幻觉，也不是「去掉传奇就反转」的借口。
- 美股同一句数学，这次没量。不能把 A 股表贴到纳指上。

已 `--declare reject`。机器和人手都不许再当「小票能稳定十倍」来做。判决不要手写 `verdict:`。

## 报告解读

1. **先读 `n` 的单位。** `n` 是名字 × 入场季。14361 不是 14361 只不重复的小票。同一只股票可以在多个季度各进一次队列。
2. **先对入场日，再比相对年化。** 每一段只拿「这一段进场的小票」对「这一段进场的大票」。不要拿 `bear_2021` 的 +9pp 去救 `crash_2015`。
3. **十倍率是密度，不是个数。** 88 次 vs 33 次看起来小票赢，除以池子之后都是 0.11%。事后数「十倍股里多少是小盘」会得到相反的故事。
4. **胜率是倍数 > 1 的路径占比**，不是「十倍胜率」。3 年股灾小票胜率 13.2%：大多数路径连本金都没回来。
5. **退市是机制，不是噪音。** 小票 1520 条退市路径进分母。把退市丢掉，十倍密度会假好看。
6. **`bull_924` 无样本不能当近窗故事。** 持有还没满 3 年。把 2024 年 10 月进场的小票现在的涨幅当成「四年十倍」，是用未完成路径撒谎。
7. **去 Top-3 只分类。** 密度几乎不动，说明原句不是靠三只传奇。即使动了，也不能单独否肥尾袖套——本句已经在相对年化上死了。
8. **跨段合计只覆盖。** 3 年小 +2.58% / 大 +0.47% 看起来小票好，但尺子写的是「任一段」。股灾段已经死。
9. **这不是选股清单。** reject 的意思是：机器人不按「只买当时小票、等十倍」跑，人也不许手做同一句。
