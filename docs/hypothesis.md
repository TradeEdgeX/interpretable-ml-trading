# 验证假设

**English:** [hypothesis.en.md](hypothesis.en.md)

人平时不用读这一页，跟 AI 说话就行（见 [README_CN.md](../README_CN.md)）。  
这一页是给 AI 的：怎么把用户的一句话收成可验证的几条。

量化回测和手写清单走同一条句子。差别只在谁执行。

---

## 1. 一句话循环

```text
人写出假设
  → AI 帮你写成可登记的特征 / 规则 / 清单（不改你的命题）
  → 程序在锁死的评测机上量（闭棒、三段、熔断关）
  → 人宣判：成立 / 不成立 / 还要更多证据
  → 成立：写进 YAML，或写成手做清单
     不成立：机器不跑，人也不许用手做同一句
```

发现吞吐不是主循环。判卷才是。

和「AI 过夜挖因子、IC 涨了就当下一轮基线」相反。那边优化的是分数；这边优化的是**一句话死没死**。

---

## 2. 同一句，两种落地

假设不是策略名，是一句带机制的话。例如：

> 价格在 50 日均线上、且刚上穿 200 日均线时做多，跌破 50 作废。  
> 我预期这在趋势年赚钱，在震荡年不亏太多。  
> 若震荡年回撤更深或年化为负，这句话作废。

| 落地 | 怎么用这句 |
|---|---|
| **量化** | 写成 `ma_cross` 一类 YAML：许可、方向、作废、仓位。`event_backtest` 出五项 KPI。 |
| **手动** | 写成清单：今天许不许做、进场条件、作废价、不许摊、时钟。到点执行，不讨论。 |

court 的 `reject` 对两种落地效力相同：**这句不能当钱用。**  
不要回测否了，晚上再手做「感觉这回不一样」。

`promote` 只表示：在约定尺子上，这句还没被证伪。  
它不是「今晚满仓」。机器人按 YAML 跑；人按清单跑。都不再现场发明第三种做法。

## 3. 怎么写假设（先写再量）

复制到实验目录的 `DECISION.md`。没写完这一段，不要下数据、不要回测。

```text
机制：      （发生了什么，才允许做）
预期市况：  （在哪类行情上该成立；在哪类上该失效）
合同：      （何时算错、错了亏哪一块、对了能不能加、何时结束）
证伪条件：  （哪一段、哪项 KPI 坏了，就判不成立）
落地：      机器人 YAML / 手做清单 / 两者同一句
```

AI 的职责：帮你收成上面五格，去重、查有没有判过。  
**禁止**把你的句子偷换成附近一条现成规则（均线交叉 ≠ 远离均线死区 ≠ 结构突破）。

先查：

```bash
mlbot research index --trusted --query <english-slug>
```

命中已结案 → 复述判决，停下。不要重扫同一句。

## 4. 特征发现（测量，不是挖分）

新列必须能回答假设里的一个词。例如「刚上穿」需要交叉事件，「作废距离」需要均线距离。

1. 给事件起名（人）。
2. 写成 FeatureStore 可算的列，登记 `config/feature_dependencies.yaml`。
3. 闭棒：开盘索引的行，只在收盘后可知。见 [math.md](math.md) §1。
4. 缺列先 backfill，不要在回测里现场 `compute_*`。

特征是**测量**。进 / 止 / 加 / 出是**合同**，写在 YAML 或清单里。  
不要把十个测量叠成一个分数，再把分数当成更强的假设。

自动组合搜索（IC 爬山、特征组搜索）只许当 Phase 1 探照灯：帮人看到「这句话在哪类场景像死了」。  
分数涨了不能结案，不能改 locked 规则。详见 [design/2026-08-23_human_hypothesis_vs_auto_mine_CN.md](design/2026-08-23_human_hypothesis_vs_auto_mine_CN.md)。

## 5. 「训练」在这里指什么

本树**不用**模型拟合当结案。没有 `mlbot train`，没有把 TimeSeriesSplit 平均分当成判决。

这里的训练是把尺子校准到可复现：

| 步骤 | 做什么 | 不是 |
|---|---|---|
| FeatureStore | 按月算列，闭棒 | 拟合预测器 |
| Phase 1 扫描 | 看这句话在标签上亮不亮、高原在哪 | 结案 |
| Phase 3 回测 | 熊 / 牛 / 近窗各跑一遍，熔断关 | 调参到顺眼 |

过拟合的通道不是「几千个系数记住了 2022-05-13」，是「扫阈值、换条件、留下好看的窗」。  
挡法：假设先写死、三段分列、坏一段就否、熔断不得用来藏回撤。问答：[agent/rd_qa.yaml](agent/rd_qa.yaml)。

## 6. 怎么量

人说「量这句」之后才启动。只想把框架写清楚时，建目录就停。

```bash
mlbot research init 20260910_<slug> --strategy ma_cross
# Phase 1（可选）
PYTHONPATH=src:scripts python scripts/rd_loop.py \
  --hypothesis-yaml config/experiments/20260910_<slug>/rd_loop_*.yaml
# Phase 3
mlbot research run 20260910_<slug>
mlbot research close 20260910_<slug>
mlbot research close 20260910_<slug> --declare reject   # 人写 verdict
```

| 必须 | 原因 |
|---|---|
| 对口 harness（公开 dummy = `event_backtest` / `ma_cross`） | 换评测机 = 换题 |
| 熊 / 牛 / 近窗三段 | 合成一段会长平均掉坏年 |
| 熔断关 | 各变体停在不同时刻，edge 不可比 |
| 五项 KPI：年化 / Calmar / 胜率 / MaxDD / Sharpe | 不要用合计 R 当头条 |

先分类再拧旋钮：这句话是 alpha、肥尾收割、beta 增强，还是无用。尺子不同。  
[design/alpha_vs_fattail_vs_beta_CN.md](design/alpha_vs_fattail_vs_beta_CN.md)

完整命令：[usage.md](usage.md)。谁写数字、谁宣判：[agent/rd_playbook.md](agent/rd_playbook.md)。

## 7. 判决怎么用在手上

| `verdict` | 机器人 | 人 |
|---|---|---|
| `reject` | 不写入 YAML | **不做这句。** 不是「减半再试」「换个标的再试」 |
| `park` / `needs-more` | 不部署 | 不下手。缺的是证据，不是勇气 |
| `promote` | 按锁定 YAML 跑 | 按同一句清单跑：许可、作废、时钟。到点执行 |

手做清单最少四格，和 YAML 对齐：

1. **许可** — 今天这类行情许不许做（慢变量 / 大位置）
2. **进场** — 主信号在不在（不要用数学噪声分代替结构）
3. **作废** — 价到了无条件结束。改出口 = 新开一笔，重走验证
4. **时钟** — 没到点不加、不换、不「再看看」

验证框架能指导手动，是因为它**拿走临场发明**。它不能代替你去盯盘找感觉。

---

## 8. 不要把它做成

- 自动挖因子、分数停了就上线
- 用交叉验证平均分代替三段判决
- 只看最近半年
- 回测否了，手做同一句
- 判决成立后，现场加一个没验过的止盈/摊平
- 把本树说成「可解释的机器学习交易机器人」
