# 假设模板

**English:** [hypothesis_template.en.md](hypothesis_template.en.md)  
循环：[hypothesis.md](hypothesis.md)

本仓库是**假设验证器**，不是挖因子机，也不是下单机器人。  
人先把现象写成模板。AI 用仓库里锁死的教训**验模板齐不齐、和尺子对不对**——不许用网页记忆说「这招一般有效」。模板过了，才许按格子编排命令。

---

## 先填这一张，再动尺子

复制进 `DECISION.md`。空格、TODO、口号都不算填完。

```markdown
## 原句
（人说的那一句。AI 不许改题。）

## 现象解剖

### 社会学
谁在付钱、什么群体行为会重复、为什么不是一句口号。
要点名付费的一方（追涨的人、被迫平仓的人、教科书共振），不要写「市场有效」。

### 数学
测量对象是什么：交叉、距离、包络、尾部、计数过程。
必须能落到 FeatureStore 的一列，并且写明**闭棒**（开盘决策只读上一根已收盘）。

### 统计学
抽样声称是什么：条件期望更好 / 肥尾少数路径 / 某因子上的暴露。
先分类：alpha / 肥尾收割 / beta 增强 / 无用。
不要用「胜率高」单独当声称。

## 验证合同

### 验证标准
哪一段、哪一项五项 KPI 坏了，这句话就死。
只用年化 / Calmar / 胜率 / MaxDD / Sharpe。不要合计 R。
熔断关着比 edge。

### 数据范围
品种、周期、日历。怎么选（粒度 / 市场自己的三段 / 无样本）：[framework.md](framework.md) §3。  
币圈默认 `bear_2022` / `bull_2023_2024` / `recent_range_to_bear`（`config/market_segment.yaml`）。  
A 股用 `market_segment_ashare.yaml`，不要套币圈日期。  
`recent_6m_oos` 不能单独结案。

## 五格
| 格 | 内容 |
|---|---|
| 机制 | 发生了什么才允许做 |
| 预期市况 | 哪类行情该成立、哪类该失效 |
| 合同 | 错了亏哪、能不能加、何时结束 |
| 证伪条件 | 与上面的验证标准同一句 |
| 落地 | 机器人 YAML 与手做清单同一句 |
```

解剖回答「为什么这是一种社会/数学/统计现象」。  
五格回答「机器和手怎么执行、怎么判死」。  
两层都要。只有五格、没有付费方和分类，例子看起来像策略说明书，不像验证器。

## AI 验模板（经验 = 本树教训，不是网上见过）

```bash
mlbot research validate <id>
```

过：结构齐、点了分类、点了五项 KPI、点了 canonical 三段、点了闭棒。  
不过：只许改模板，不许下载、不许建特征库、不许回测。

agent 对照的「经验」只有这些：

| 来源 | 挡住什么 |
|---|---|
| [lessons.md](lessons.md) | 开盘读同根、熔断开着排名、合计 R、只看近窗 |
| [philosophy.md](philosophy.md) §5 | 用错尺子（拿去 Top-3 杀趋势袖套） |
| [features.md](features.md) | 回测里现场 `compute_*` |
| `mlbot research index --trusted` | 已经宣判的同一句再扫一遍 |

**禁止**用训练语料或网页文章当「经验验证」。那是换一个模型就变的故事，正是本树要关掉的。

## 模板过了，才编排

| 格子 | 许编排的命令 | 仍不许 |
|---|---|---|
| 数学点名了新词 | 登记 `*_f`，缺列才 `feature-store build` | 没让测就建库 |
| 数据范围 | `mlbot data`（人说了测） | 手写 kline |
| 验证标准 + 三段 | `mlbot research run`（熔断关） | 换评测机、合成一段 |
| 五格落地 | YAML 或清单，同一句 | 现场加没验过的止盈/摊 |
| 数字出来 | `mlbot research close`；人 `--declare` | AI 写 `verdict` |

没说「测一下」：`validate` + `init` + 谱系查询就停。

## 金叉怎么填（示范解剖，不是新结论）

| 格 | 金叉这一句 |
|---|---|
| 社会学 | 教科书 50/200 是协调仪式。单边年，后知后觉的趋势盘在付已站上的人；震荡年他们互相付手续费。 |
| 数学 | 闭棒 EMA50、EMA200；事件是 `ema50-ema200` 变号；作废是收盘跌破 EMA50。 |
| 统计学 | 先当 **beta / 趋势暴露**，不是选点 alpha。三段分列；近窗年化为负则整句死。 |
| 验证标准 | 任一段年化 &lt; 0，或震荡段回撤深于趋势段。 |
| 数据范围 | BTCUSDT · 2 小时 · `market_segment.yaml` 三段。 |
