# 哲学原理

**English:** [philosophy.en.md](philosophy.en.md)  
上手循环：[验证假设](hypothesis.md)。

---

## 1. 系统在优化什么

不是利润最大值。是**可幸存的学习**：在真实行情阶段上，尽快确认一句完整的交易话行 / 不行 / 在什么条件下行。

> 完整闭环 × 真时间成本 = 真实认知。半道不算数，压缩时间的回测也不算数。

「速」是证伪收敛的速度，不是暴利速度。

---

## 2. 信息分层（不可越权）

| 箴言 | 问题 | 数据 |
|---|---|---|
| Price tells you WHAT | 发生了什么 | 价格 / 结构 |
| Volume tells you IF | 是否被市场接受 | 量能 / 参与度 |
| Order flow tells you WHO | 是谁在推动 | 订单流 / 成交聚类 |
| Math tells you HOW CAREFULLY | 该有多保守 | 噪声 / 尾部 / 频谱 |

没有任何一层能替另一层做决定。结构说「这是突破」，数学不能改口说「那就不算突破」；数学只能说「噪声高，仓要小 / 止损要近」。

分权：

> Gate 保护正确性。Execution 决定暴露。Math 控制谨慎。账户闸门管生存（挡新开，不是持仓中途强平）。

---

## 3. 启发式是先验，框架负责证伪

「订单流真空不做突破」「回踩太浅是假形态」——这些是交易哲学，不是模型发现的。

树、NN、IC、lift 可以用来**在历史上反证**「哪些子场景成功率掉下去」。决策仍是一句人写的规则（YAML 或手做清单）。工具可以换，证伪循环不能换：

```
假设（人脑启发式）
  → 在特征上扫描（只生成更尖的假设）
  → 事件回测（canonical 三段，关熔断）
  → 人审：可解释 + 跨段同号 + 风险不恶化
  → 锁定，或 REJECT
```

IC 为正不能上线。单窗漂亮不能上线。熔断截断后的曲线不能拿来比 edge。  
回测否了的句子，也不能改用手做。

## 4. Popper，不是调参

| 步骤 | 在本仓库里的实体 |
|---|---|
| 假设 | 一句机制 + 合同（YAML 或清单） |
| 测试 | 回测 / 失败审计 / 去 Top-3（仅作分类） |
| 证伪 | 跨段翻号、未来函数、摩擦后归零 |
| 更新 | 删规则、标 RETIRED、人手也不再做这句 |

下一轮只打「判决还盖不住的 failure」。系统最小化的是**已知错误之外的未知错误**，不是夏普。

---

## 5. 先分类，再决定怎么拧

| 类型 | 钱从哪来 | 判据 | 不该做的 |
|---|---|---|---|
| **Alpha** | 条件期望更好 | 去 Top-3 仍正；中位/胜率跨段同号 | 用牛市右尾证明 alpha |
| **肥尾收割** | 少数极端路径 | 总和由 Top-3 主导，中位常负 | 为提高胜率砍右尾 |
| **Beta 增强** | 点名因子上的暴露 | 扣因子后残差≈0 | 用短周期探测器「保护」长 beta |
| **无用** | 无 | 跨段≤0 | 继续扫阈值 |

探测器选路径；收割器（加仓 / 长持 / 结构退出）决定踩上后吃多厚。不要把执行红利记成信号 alpha。

口诀：**因子 = 共同付费来源；beta = 你在上面的暴露；alpha = 扣完这些暴露还多的钱。**  
统计上「看起来像 alpha」的大半住在 beta 里。对齐同窗长持 + 相近回撤之后残差经常 ≈ 0。那是 beta 增强 / 肥尾收割，不是更聪明的选点。

长文：[design/alpha_vs_fattail_vs_beta_CN.md](design/alpha_vs_fattail_vs_beta_CN.md)。去 Top-3 不能单独否决趋势袖套：[design/ex_top3_capacity_confound_CN.md](design/ex_top3_capacity_confound_CN.md)。

## 6. 图是合同，不是第二套预测

交易必须有合同：何时进、何时算出错、错了亏多少、对了能不能加、什么叫这张单结束。图形把 K 线收成 **里 / 外 / 作废**。这是可执行的句法，量化 YAML 和手做清单写的是同一件事。

| 层 | 只回答 | 不回答 |
|---|---|---|
| 慢均线 / regime | 今天许不许多 / 空 / 观望 | 进场点 |
| 大位置 | 值不值得签一张单（贴沿 vs 肚子里） | 方向许可（已由 regime 回答） |
| 结构沿 | 这一张的止损、失效、对侧 | 改口去用另一层当止损 |

消融不是「不要合同」，是合同写在哪一层几何上。**没有零合同的交易。**  
不要把均线 + 位置 + 结构拧成一个箭头指标。
