# DECISION — 20260911_tenbagger_smallcap

## 原句

A 股涨十倍的，一般要在 100 亿市值以下，拿三到四年。美股是不是也这样？  
（调研未来谁会十倍、故事还没发生 —— **不是**这一句。这一句只量历史规则。）

## 现象解剖

### 社会学

十倍是少数路径上的彩票，不是「选股 alpha」。小市值池子里，叙事、壳、主题轮动让后到的人付钱给已经在场的人。付费方是追逐十倍故事的人。还没上市、还没涨的名字，没有历史可以量。

### 数学

在**入场日已知**的流通市值（闭棒：当日成交额 / (换手率/100)）上设阈值 ≤ 100 亿元人民币。持有固定 3 或 4 个**交易年**（252×3 / 252×4 根日线），看终端倍数是否 ≥ 10。禁止用「后来成为十倍股」回看当时市值——那是用未来贴标签。退市用最后收盘作终端。

### 统计学

先当 **肥尾 / 小市值 beta**，不是选点 alpha。去 Top-3（或去最大几个十倍）只作分类，不能单独用来否这条袖套。对照是同时点市值 > 100 亿的同一持有期。抽样按入场日所在 A 股政权窗分列，不要合成一条「十倍概率」。

## 验证合同

### 验证标准

任一段：小市值组相对大市值组的年化 ≤ 0，或十倍命中率不高于对照且 Calmar 更差。
只用年化 / Calmar / 胜率（倍数>1） / MaxDD / Sharpe。熔断关。
近窗子窗不可独自 promote。

### 数据范围

**A 股：** 沪深 A 股日线前复权 + 季度时点成分（`universe_hist`）+ `market_segment_ashare.yaml`。持有 3–4 年按**入场日所在段**分桶。`bull_924` / `chop_recent` 入场尚不能完成 3 年持有 → 无样本。美股未量。

评测机是 **cohort_hold**（入场日 × 宇宙 × 固定年数），不是 `event_backtest`。

## 五格

| 格 | 内容 |
|---|---|
| 机制 | 入场日流通市值 ≤ 100 亿的股票进来；持有 3 或 4 个交易年；不择时加仓。 |

| 落地 | 机器：`scripts/research/cohort_hold.py`。人手：只买当时已知小票、日记入场日、拿满年数。 |
