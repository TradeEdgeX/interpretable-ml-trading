# DECISION — 20260911_ashare_cs_mom_amount

## 原句

过去 20 日涨得多、且自身成交额也热的股票，未来 20 日相对全市场等权继续涨。

（大盘择时、北向、主力净流入、自动搜因子 —— **不是**这一句。因子两列事先锁死，IC 只探照灯，不改题。）

## 现象解剖

### 社会学

涨得多的票吸引追涨的人；成交额热说明已经有人在付钱。后到的人继续买这些名字，已经在场的人把货卖给他们。付费方是追热度的人。两列叠在一起仍是同一群人，不是第三个神秘因子。

### 数学

单票闭棒列：`mom_20` = 收盘 / 20 根前收盘 − 1；`amount_z_20` = 成交额相对自己过去 20 根的 z 分数。  
横截面：每个交易日对两列分别做截面 z，`score = 0.5 * cs_z(mom_20) + 0.5 * cs_z(amount_z_20)`。  
IC：当日 `score` 与「下一根开盘起 20 个交易日开盘收益」的 Spearman。标签可以看未来。  
书：当日收盘算分，下一根开盘进前 20%，再下一根开盘记一天收益（闭棒）。对照是同一天全部可打分名字的等权。不加仓、不空。

### 统计学

抽样声称：高分名字相对全市场等权，20 日条件期望更好。  
统计先当 **beta**（动量 + 活跃度暴露），不是选股 alpha。未做行业中性、未做市值中性。  
IC 是 Phase 1。分数涨了不能结案。结案看三段书的五项 KPI。

## 验证合同

### 验证标准

`bear_2021` / `bull_924` / `chop_recent` 任一段：高分组长相对等权对照年化 ≤ 0，这句话就死。  
只用年化 / Calmar / 胜率 / MaxDD / Sharpe。熔断关。IC 不能单独结案。

### 数据范围

全部 A 股日线（`type=1`，去掉 ST）。周期 1D。
