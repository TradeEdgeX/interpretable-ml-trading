# DECISION — 20260911_ashare_bear_short_index

## 原句

再熊市做空指数，熊市也能赚钱。

（用 `bear_2021` 标签当交易信号 —— **不是**能上手的一句。标签是事后切的。能测的闭棒：沪深300 收盘在 200 日均线下才空。）

## 现象解剖

### 社会学

指数跌的时候，做多指数的人付钱给空头。付费方是还在扛指数的人。事后知道「那是熊市」再空，是看了答案；当时场上的人并不拿着这张日历。

### 数学

指数 `000300.SH`。时钟与横截面书相同：收盘决策，下一根开盘进，再下一根开盘记一天。  
看答案本：信号 = 日历落在 `bear_2021`。没有闭棒列。  
闭棒本：`close < MA200`（当日收盘可知），是则做空，否则空仓。  
叠在因子上：同一天再空一份指数，或熊信号时改空指数。不改「热票相对等权续涨」那句。

### 统计学

抽样声称：熊段账户年化为正。  
统计先当 **beta**（空指数），不是因子 alpha。看答案本不能结案。闭棒本必须三段分列：熊赚、牛亏是同一枚硬币。

## 验证合同

### 验证标准

看答案本：不算法庭。  
闭棒本：`bear_2021` / `bull_924` / `chop_recent` 任一段年化 < 0，这句话就死。  
只用年化 / Calmar / 胜率 / MaxDD / Sharpe。熔断关。

### 数据范围

`000300.SH` 日线。日历 `market_segment_ashare.yaml`。因子叠层用已量的 `daily_books.parquet`。
